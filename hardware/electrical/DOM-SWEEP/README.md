# DOM-SWEEP 基板

ロボットの本体基板です。**KiCad** で設計しています。

## 主な部品

| 役割 | 部品 |
| --- | --- |
| マイコン | STM32F446RET6（クロック: 10MHz セラミック発振子 CSTNE10M0G55A000R0） |
| モータドライバ | SLA7073MPRT ×2（左右のステッピングモーター用。J1 / J2） |
| 電源 | NJM7805（5V）、NJU7223F33（3.3V）、逆接続防止ダイオード 1N4007 |
| 壁センサ | 赤外 LED OS5RKA5111P ×4 ＋ フォトトランジスタ ST-1KL3A ×4 |
| その他 | ブザー UGCM1205XP、タクトスイッチ ×3、電源スイッチ、デバッグ用ヘッダ J3（2×3）、拡張ヘッダ J4（2×10） |

部品の全リストは `DOM-SWEEP.csv` を見てください。

## 足りないもの：部品ライブラリ `new_freshman_cm`

この回路は、独自の部品ライブラリ `new_freshman_cm`（シンボルとフットプリント）を使っています。そのライブラリはこのリポジトリにまだ入っていません。

- 回路図と基板を開いて見るだけなら、ライブラリがなくても大丈夫です（使っている部品のデータはファイルの中に入っています）
- 部品を追加・変更する場合は、ライブラリを `hardware/electrical/lib/new_freshman_cm/` に置いてください（`fp-lib-table` と `sym-lib-table` はこの場所を参照しています）

## 更新するときのルール

- KiCad のファイルは 2 人が同時に編集すると衝突します。**編集する前に声をかけてください**
- 基板を発注したら、そのときのコミットにタグを付けておくと、どの版を発注したか後から分かります（例: `board-v1`）
