# CAD データ

機構設計のデータを置く場所です。CAD ソフトは **Fusion 360** を使います。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `Mice_Sweep.f3z` | 機体全体のアセンブリ（ルート: 「全体」） |

`Mice_Sweep.f3z` に含まれる主な部品:

- 足回り: タイヤ、ホイール、モーターマウント、PKE243A-L（ステッピングモーター）
- ボール吸引機構: Miceボール吸引機構、吸引ファン1、吸引筒、吸引モータ、ボール把持機構ステー v2(M3ver)
- アーム: RS204MD（サーボ）、サーボ連結部品
- 基板・その他: 上基盤改、下基板、センサーホルダー、角型スペーサ

## 開き方

Fusion 360 のデータパネルで「アップロード」を押し、`.f3z` ファイルを選びます。

## 更新するときのルール

- `.f3z` はバイナリファイルなので、2 人が同時に編集すると片方の変更が消えます。**編集する前に Issue かチャットで声をかけてください**
- 更新したら、Fusion 360 で「ファイル → エクスポート → .f3z」で書き出し、同じファイル名で上書きしてコミットしてください
- コミットメッセージには、どの部品をどう変えたかを書いてください（例: `吸引筒の内径を 72mm に変更`）
- 公式の参考機体「ムブアイ」の CAD（STEP）は、ライセンス上このリポジトリに置けません
