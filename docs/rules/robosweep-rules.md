## 1. チームにとって大事なこと

| | 内容 | 条 |
| --- | --- | --- |
| 🎮 | **1 台だけリモコンで操作してよい**。操作できるのはチームの 1 人だけで、1.0m × 1.0m のオペレーションエリアから操作する。ほかの機体は自律 | 4-13、注意 1・2 |
| 🚫 | オペレーションエリアから電子機器でフィールドの様子を測る（カメラで盤面を見るなど）のは禁止。機体に付けたカメラは問題ない | 注意 3 |
| ⚖️ | 出場する機体の**合計重量は 2.0kg 以内**。台数の制限はない。機体の大きさの制限は書かれていない | 1-6 |
| 🧱 | 機体の**全部または一部**が相手陣地に入ってはいけない（回収するときも同じ） | 1-5 |
| ⚠️ | **ボールをフィールドの外に出すと負けになることがある**。最後に触ったチームの相手陣地にも相手の機体にも触れずに外へ出たら、最後に触ったチームの負け | 4-12 |
| 📡 | 機体どうしで通信してよい。ただし会場の電波の状態は保証されず、つながらなくても文句は言えない | 1-7、4-11 |
| 🔧 | 試合中に機体のハード・ソフトを変えてはいけない | 1-2 |
| 🙋 | 試合中いつでも、手を挙げて審判の許可をもらえば機体を回収でき、審判が指定するスタート区画に置き直せる。そのときボールに触ると 1 点減点 | 4-14、4-15 |
| 👤 | 同じ製作者（＝オペレーター）が登録できるのは 1 チームだけ | 注意 9 |

### このチームの設計への影響

- **リモコン機を 1 台出せる**。今のリモコン機（DOM-SWEEP）はそのまま競技に出せる。2 台目以降は自律にする。
- **壁越しに投げる方法（Issue #11）は、次の 2 つに注意する**。
  - 投げたボールがフィールドの外へ飛ぶと**負け**（4-12）。投げる強さと向きは、外に出ない範囲にする。外周の壁の近くでは投げない。
  - 「機体の一部でも相手陣地に入ってはいけない」（1-5）。**投げるときにアームが壁の上から相手陣地の側に出ると反則になるおそれがある**。壁越しに投げてよいことは大会に確認したが（2026-11-12、チームより）、アームがどこまで出てよいかも確認しておく。
- 合計 2.0kg の中で、台数と 1 台の重さの配分を決める。

## 2. 競技規程（要約）

### 前文
ロボット（規程では「エージェント」と呼ぶ）が、自陣地の未知のフィールドにある複数のボールを自分で見つけて相手陣地へ送り込む。試合中に何回か各陣地のボールの数を数え、その結果で得点を競う。

### 1. エージェント

| 条 | 内容 |
| --- | --- |
| 1-1 | 自立型であること。燃焼を使うエネルギー源は禁止 |
| 1-2 | 試合中に操作者がハード・ソフトの追加・取り外し・交換・変更をしてはいけない |
| 1-3 | 壁を飛び越える・よじ登る・傷つける・壊すのは禁止 |
| 1-4 | フィールドを変形させたり、ボールを壊したりしてはいけない |
| 1-5 | 機体の全部または一部が相手陣地に入ってはいけない（回収するときも含む） |
| 1-6 | 出場する機体の合計重量は 2.0kg 以内。同時に出す台数に制限はない |
| 1-7 | 通信などで情報をやりとりしてよい。通信環境は用意されず、会場の状態に従う。通信の状態について異議は認めない |

### 2. フィールド

| 条 | 内容 |
| --- | --- |
| 2-1 | 壁の側面は白、壁の上面は赤、床は黒。床は木材に黒のつや消し塗装 |
| 2-2 | 18cm × 18cm の区画が 16 × 16。壁の高さ 5cm、厚さ 1.2cm（[図1](https://ntf.or.jp/robosweep/wp-content/uploads/2025/11/画像1.png)） |
| 2-3 | 区画の四隅の 1.2cm 角の部分を「格子点」と呼ぶ。格子点に必ず壁があるとは限らない |
| 2-4 | フィールドは中心について点対称な 2 つの陣地に分かれる（陣地が長方形とは限らない。[図2](https://ntf.or.jp/robosweep/wp-content/uploads/2025/11/画像2-1024x1024.png)）。2 つの陣地は壁で分かれていて行き来できない。各陣地の四隅の区画が始点で、スタートゲートがある |
| 2-5 | 自陣地のどの区画にも、どの始点からも走って行ける |

### 3. ボール

| 条 | 内容 |
| --- | --- |
| 3-1 | 試合の開始時、両陣地の決められた位置に 2 個ずつ置く。位置は事前に公表される |
| 3-2 | ポリウレタンが主な材料 |
| 3-3 | 直径 70mm（±3mm 以下）、重さ 19g（±3g 以下） |
| 3-4 | 表面の 90% 以上が黄色 |
| 3-5 | ボールを壊してはいけない。粘着剤などでボールの性質を変えてはいけない |

### 4. 競技

| 条 | 内容 |
| --- | --- |
| 4-1 | 試合時間は 5 分。終了時の合計得点が多いチームの勝ち。同点なら審判が判定する |
| 4-2 | 試合中、開始前に決めたタイミングで計 5 回、各陣地のボールの数を数える。自陣地のボールが少ないチームに 1 点 |
| 4-3 | フィールドの形は試合開始まで公開されない。機体が開始前にフィールドの情報を知ってはいけない |
| 4-4 | 競技委員長のスタートの合図で始まり、同時に各陣地の四隅のスタートゲートが開く |
| 4-5 | 自陣地の四隅の始点のどれからスタートしてもよい。スタートゲートの向きは事前に公表される |
| 4-6 | 操作者は、競技委員長の指示・試合終了・走行の中断のとき以外、走っている機体に触れてはいけない |
| 4-7 | 得点の判定と勝敗の判定は審判が行う。異議を受け付けるかは競技委員長が決める |
| 4-8 | 照明・温度・湿度は演出で変わることがある。調整の申し出は受け付けない |
| 4-9 | 競技委員長は、機体の説明を求めたり、走行の中止・失格などを決めたりできる |
| 4-10 | 表彰の内容と基準は大会ごとに決める |
| 4-11 | 会場の電波環境は決められていない。操作者・観客は電波法の範囲で電波を使える機器を使ってよい |
| 4-12 | ボールがフィールドの外に出たら、そのボールを除いて続ける。ただし、最後に触ったチームの相手陣地にも相手の機体にも触れずに外へ出たら、最後に触ったチームの負け。全部のボールが外に出たら競技委員長が判断する |
| 4-13 | チームの 1 人だけが、オペレーションエリアから機体を遠隔操作できる。遠隔操作できるのは 1 台だけ |
| 4-14 | 試合中いつでも（走行中・停止中・故障中を問わず）機体を回収できる。審判が指定するスタート区画に置き直して復帰できる。復帰させないなら電源を切る |
| 4-15 | 回収・復帰は、手を挙げるなどして審判の許可をもらい、相手陣地に入らない範囲で行う。回収・復帰の途中でボールに触ると 1 点減点 |

### 注意事項

1. 試合中、オペレーションエリアからコントローラなどで 1 台を遠隔操作してよい
2. オペレーションエリアは 1.0m × 1.0m で、1 人だけ入れる
3. オペレーションエリアから電子機器でフィールドの様子を測るのは禁止
4. 試合中は、回収のとき以外、フィールドの外周から 1m 以内に入らない
5. 試合の前にタイヤのほこりを粘着テープなどで取るのはよい。摩擦を増やす溶剤などは禁止
6. 調整などのため、走るとき以外は、始点の区画以外に機体を置いてはいけない
7. フィールドは普通の工作精度で作られるので寸法に誤差がある。組み替えられるように作るので、壁や床に 1mm くらいのすき間や段差ができることがある
8. 規程にないことは審判の指示に従う
9. 同じ製作者（＝オペレーター）が参加登録できるのは 1 チームだけ

### 規程に書かれていないこと

- 機体の大きさの制限
- 無線の周波数や出力の決まり
- 反則の一覧と罰則（回収時にボールに触ると 1 点減点、ボールをフィールドの外に出すと負け、以外）
- 試合の前のセッティングの時間や手順

これらは大会ごとの要項（[イベント・大会情報](https://ntf.or.jp/robosweep/contest/)）も確認する。

## 3. 参考になる資料

### 2026年度 関西地区大会
[マイクロマウス委員会 関西支部の告知](https://mmk.rulez.jp/?p=3079)、[迷路の画像](https://ntf.or.jp/robosweep/wp-content/uploads/2026/07/FY26関西地区大会迷路.jpg)、[対戦表](https://ntf.or.jp/robosweep/wp-content/uploads/2026/07/FY26関西地区大会結果.png) より:

- 2026年度から始まった種目。参加費は無料
- 迷路は 16 × 16 区画で、中央の太線で左右の陣地に分かれていた。ボールは各陣地に 2 個
- 6 チームのトーナメント。スコアは「0-5」「2-0」「0-3」「0-0」など
- 表彰は優勝・準優勝・特別賞

### 優勝チームの構成
[エントリーシート](https://ntf.or.jp/robosweep/wp-content/uploads/2026/07/2026kansai_entry_1.pdf) より:

- 同じ機体 2 台で 1 チーム。迷路を半分ずつ担当していた
- 2 台は Wi-Fi ルーターにつないだ同じ LAN で通信していた
- ボールを吸引でつかみ、バネで打ち出す
- カメラで黄色い部分を見つけてボールを検出していた
- 主な部品: Raspberry Pi 5、ESP32-S3、ATmega328、IR 壁センサ、IMU、エンコーダ

### 公式の参考機体「ムブアイ」
三菱電機が、競技の参考になる機体の資料を公開しています（[ntf.or.jp/robosweep の uploads](https://ntf.or.jp/robosweep/wp-content/uploads/2026/06/)）。

- `機体HW.zip`: 回路図、CAD（STEP）、ハードウェアの説明
- `ファームウェア.zip`: RX66N と FreeRTOS で動くファームウェアと説明資料
- `調整ソフト.zip`: Windows で動く調整用の GUI
- `ライセンス規約.pdf`

機体の主な仕様（ハードウェアの説明より）:

- 重さ約 450g、最高速度の目標 2m/s
- バッテリー Li-Po 2S 900mAh（連続 20 分を想定）
- Raspberry Pi 4B（通信・アルゴリズム）と RX66N（制御）
- 2 軸アームと遠心ファンでボールを吸着する

> ⚠️ **ムブアイの資料はこのリポジトリに置かないでください。**
> ライセンス規約は「社外秘」扱いで、配布できるのは「本競技を目的とする開発グループ内」までです。
> **不特定の第三者への配布は禁止**されています。商用利用も禁止です。
> このリポジトリは Public なので、zip・PDF・CAD・ソースコード（改変したものも含む）をコミットすると規約違反になります。
> 各自が上の URL からダウンロードしてください。
